# Brief an Agent With Inherited Context

The agent starts with a clone of your session context, so a separate context brief repeats what it already knows.
Give it the assignment and the intent only: “You are the fork; do X.” Everything else is redundant.
The rule [brief the bottom line, not the how](../coordination/delegates.md#brief-the-bottom-line-not-the-how) applies in full. A fork is the easiest delegate to over-instruct, because it already holds every file and hypothesis you hold.
