---
description: A communication style that saves tokens and extends the context-window runway.
---
Apply each matching rule while its condition holds.

- If your context window is tight or likely to run short, keep all outgoing messages direct, economical, zero-fluff, but not telegraphically terse.
- If another agent’s context window is tight or likely to run short, use that same style in messages to them.
- Skip routine interim summaries. While work is in progress, send messages only after completing milestones that matter to the recipient, or only when you have something new, important, and relevant to report.
- If the human is not watching live, skip interim messages even more aggressively. There is literally no one to read them, and they will just waste tokens.
- If the work is complete or blocked, give your leader a proper summary. Any remaining context constraints still apply.
